# Engenheiro Eletricista | Engenharia de Dados · Análise de Dados · Confiabilidade Industrial

Engenheiro Eletricista com foco na interface entre **engenharia elétrica, análise de dados e confiabilidade industrial**. Gosto de entender o problema físico antes de modelá-lo e transformar dados industriais em análises, indicadores e modelos preditivos.

## Projetos

[**⚡ GridPulse — Pipeline de Dados e Machine Learning para o Sistema Elétrico Brasileiro**](https://github.com/Marcelao98/Gridpulse)
Pipeline end-to-end para **previsão do consumo de energia elétrica no Brasil para o dia seguinte**, combinando engenharia elétrica, análise de dados e machine learning. O projeto integra dados do ONS e meteorológicos, utiliza **arquitetura medalhão (Bronze, Silver e Gold)**, processamento em Python, modelo **XGBoost** e infraestrutura containerizada com **Docker**.

[**🔧 Manutenção Preditiva — NASA CMAPSS**](https://github.com/Marcelao98/data-notebooks/tree/main/nasa-cmapss-rul)
Série completa sobre predição de Vida Útil Remanescente (RUL) de motores turbofan: EDA com métricas PHM, análise de sobrevivência (Kaplan-Meier, Weibull), feature engineering, XGBoost com SHAP e LSTM.

[**🏭 Riverflow — Pipeline de Dados para Confiabilidade**](https://github.com/Marcelao98/Riverflow)
Projeto end-to-end simulando 3 anos de histórico de uma planta industrial: modelagem de falhas com Weibull em Python, Data Warehouse com Star Schema em SQL, KPIs de manutenção (MTBF, MTTR, Disponibilidade) e dashboards no Tableau.

## Tecnologias

**Dados & ML:** Python · Pandas · NumPy · Scikit-learn · XGBoost · TensorFlow · SHAP

**Engenharia de Dados:** SQL · PostgreSQL · Docker · ETL/ELT · Arquitetura Medalhão · Data Warehousing

**Visualização & BI:** Power BI · Tableau · Matplotlib · Plotly
